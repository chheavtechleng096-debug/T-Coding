Electrical Circuit Simulator

Add a Java-based electrical circuit simulator that allows users to create, simulate, and analyze series and parallel circuits.

Features

* Add and manage circuit components.
* Simulate series circuits.
* Simulate parallel circuits.
* Analyze electrical circuits using Java.
* Provide a graphical user interface with Java Swing.

Technologies

* Java
* Java Swing and AWT
* Eclipse IDE

How to Run

1. Import the project into Eclipse IDE.
2. Open Main.java.
3. Run the application.
